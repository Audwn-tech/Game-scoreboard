Scorekeeper.

A simple, responsive scorekeeping web app built with HTML, CSS, and JavaScript.

The project started as a basketball scoreboard, but the goal is to develop it into a flexible scorekeeper that can be used for different sports, games, and competitions.

Features:

Add 1, 2, or 3 points to either player or team
Subtract points when needed
Custom player/team names
Player/team names saved with localStorage
Count-up game timer
Start, pause, and reset timer
Reset scores
Automatic leading-team indicator
Responsive layout for desktop, tablet, and mobile
Custom digital scoreboard font
Button hover and active states
Layout prepared for future advertisements
How It Works

Enter the names of the two players or teams and use the scoring buttons to keep track of the game.

The score and timer can be controlled independently, allowing the scoreboard to work for different types of games.

Why I Built This

This is a learning project I'm using to improve my understanding of JavaScript, DOM manipulation, and application state.

Rather than stopping at a basic scoreboard, I'm gradually adding features and improving the project as I learn. The long-term goal is to make it something that could actually be useful rather than just a tutorial project.
